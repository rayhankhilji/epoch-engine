# Epoch

**A simulation engine for intelligence.**

Hundreds of autonomous LLM agents living inside a persistent world grounded in real Earth —
real cities, real weather, real markets, real news. They think, act, trade, befriend, betray,
build companies and change the world. Then you watch it happen.

> What Unity did for games, Epoch does for AI societies.

🚧 Under active construction. Full documentation lands with `v0.1`.
